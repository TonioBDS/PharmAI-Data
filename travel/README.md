# Données de voyage (à venir)

Informations par destination (points d'attention connus selon la saison : soleil, moustiques,
tiques…), un fichier par pays (`destinations/PT.json`) ou par région (`destinations/FR/GF.json`).
Chaque information cite sa source et sa date de relevé. Mises à jour proposées chaque mois
sous forme de pull request, publiées seulement après relecture.

Ces données ne recommandent aucun traitement : pour un sujet médical (paludisme, vaccins),
l'app renvoie vers un médecin et vers la page officielle du pays.
